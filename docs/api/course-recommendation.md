# 수강 추천 API

`GET /api/v1/course-recommendations?academicYear=2026&term=SECOND`는 인증된 학생 본인의
정규학기 수강 과목을 규칙 기반으로 추천합니다. 결과는 안내이며 수강 신청 자격, 선수과목,
정원을 확인하지 않습니다. 데이터는 저장하지 않습니다.

## 입력과 범위

- `term`은 `FIRST` 또는 `SECOND`만 받습니다. 권장 학기가 정규학기 기준이라 계절학기는
  `400 INVALID_REQUEST`입니다. 연도는 2000~9999입니다.
- 학생의 활성 전공(주전공 → 복수전공 → 부전공 순서)마다 **해당 연도에 공개된** 그 학과의
  교과과정 연결을 후보로 씁니다. 성적 인정 기준과 같은 학과·수강연도 연결입니다.
- 후보 구분은 전공필수, 전공선택, 전공기초, 교양필수입니다. 교양선택과 일반선택은 추천하지 않습니다.
- 같은 과목은 앞 전공에서 한 번만 추천합니다(공통 교양필수가 전공마다 연결된 경우).
- 해당 학기 개설 강의(`lecture`)가 하나라도 등록돼 있으면 개설된 과목만 추천하고 분반을
  함께 돌려줍니다. 하나도 없으면 `lectureDataAvailable=false`이고 개설 여부로 거르지 않습니다.

## 추천 규칙

`semesterNumber`는 추천 학기보다 앞선 정규학기 중 성적이 있는 학기 수 + 1입니다.
휴학은 반영되지만 성적을 입력하지 않은 학기는 세지 않습니다. 권장 학년·학기는
`(학년-1)*2 + 학기`로 같은 번호 체계에 놓고, `BOTH`는 그 학년의 두 학기를 모두 뜻합니다.

| 이유 | 조건 |
| --- | --- |
| `GRADUATION_REQUIRED` | 학생 입학년도·전공의 졸업요건 필수과목이고 아직 이수하지 않았으며, 권장 학기가 지났거나 이번이거나 권장 학기가 없음 |
| `OVERDUE` | 미이수이고 권장 학기가 지남 |
| `RECOMMENDED_NOW` | 미이수이고 이번이 권장 학기 |
| `RETAKE` | 재수강으로 대체되지 않은 최근 성적이 C+ 이하, F, NP (`previousGradeCode`에 최근 등급) |

- 이수는 졸업 진행률과 같습니다. RPL과 F·NP가 아닌 등급이 이수이고, 재수강으로 대체된 성적은 보지 않습니다.
- C+ 이하로 이수한 과목은 `RETAKE`만 붙습니다. 같은 과목에 C+ 초과 성적이나 RPL이 있으면 추천하지 않습니다.
- 권장 학기가 아직 오지 않은 과목은 졸업 필수여도 추천하지 않습니다(재수강 제외).
- 정렬은 첫 번째 이유(위 표 순서) → 권장 학년 → 학수번호입니다.
- 재수강 기준 C+ 이하는 인하대 학칙 값을 상수로 둔 것입니다(`CourseRecommendationCalculator`).

## 응답과 오류

- 교과과정이 공개되지 않은 전공은 `curriculumAvailable=false`, 빈 `courses`입니다.
- 졸업요건 정책이 없는 전공도 오류 없이 졸업 필수 표시만 빠집니다.
- `401`: 인증 실패, `404 STUDENT_NOT_FOUND`: 학생 프로필 없음, `400 INVALID_REQUEST`: 계절학기·연도 범위·파라미터 형식 오류.

## 범위 밖

선수과목, 시간표 충돌, 수강 정원, 교양선택 영역 추천, 학점 상한, 교수 선호도, 계절학기 추천.
